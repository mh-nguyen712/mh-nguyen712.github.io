\section{Open-source Projects}
\begin{tabularx}{\linewidth}{ @{}l r@{} }
\textbf{Blind deblurring in Fluorescence Microscopy} & \hfill \href{https://deepblur.mambo-utoulouse.fr/}{Online demo}
\\[3.25pt]
\multicolumn{2}{@{}X@{}}{
	Designing deep learning-based methods to jointly estimate the sharp image and the unknown blur kernel from a single blurred fluorescence microscopy image. 
	We address diffraction-limited blurs based on Zernike polynomials, spatially varying blurs and 2D/3D settings. 
	Efficient implementation in PyTorch and ongoing validation on various microscopy settings (RIM, TIRF, confocal). Joint work with \href{https://pierre-weiss.github.io/}{Pierre Weiss}, \href{https://fsarron.github.io/}{Florian Sarron}, \href{https://pescande.perso.math.cnrs.fr/}{Paul Escande} and opticians \href{https://scholar.google.fr/citations?user=hPebN5AAAAAJ}{Thomas Mangeat}, Sylvain Cantaloube. Presented at \href{https://imabio-cnrs.fr/mifobio-2025/}{MIFOBIO-25}.  
	\vspace*{0.25cm}
}  
\\ %\vspace*{0.5cm}
\textbf{DeepInverse -- Core contributor and maintainer} & \hfill \href{https://github.com/deepinv/deepinv}{Link to Github} 
\\[3.25pt]
\multicolumn{2}{@{}X@{}}{
	An open-source PyTorch-based library (part of the \href{https://pytorch.org/blog/deepinverse-joins-pytorch-ecosystem/}{PyTorch Ecosystem}) for solving imaging inverse problems with state-of-the-art deep learning based methods. \texttt{deepinv} accelerates research across imaging domains, enhances research reproducibility via a common modular framework of problems and algorithms. 
	Responsibilities: core library API design/contribution, benchmarks, CI/CD, packaging, docs, and community support.
